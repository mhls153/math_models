# 数学建模算法工坊 · MathModel Studio

面向 **全国大学生数学建模竞赛（CUMCM 本科组 A/B/C 题）** 与 **美国大学生数学建模竞赛（MCM/ICM A–F 题）** 的交互式数学建模算法实验台与备赛指南。所有数值计算、矩阵分解、单纯形/分支定界寻优与可视化均在浏览器本地完成。

## ✨ 核心特性

### 1. 竞赛与备赛专栏（5 大模块）
- 🇨🇳 **国赛指南（CUMCM）**：本科组 A 题（连续物理/工程机理）、B 题（离散运筹/优化算法）、C 题（数据分析/统计运筹决策）题型对比、高频算法映射及开源论文库直达。
- 🇺🇸 **美赛指南（MCM/ICM）**：MCM（A 连续 / B 离散 / C 数据洞察）与 ICM（D 运筹网络 / E 可持续环境 / F 政策科学）六大题型解析、O 奖摘要（Summary Sheet）黄金法则与双语论文库。
- ⚖️ **评审标准与检验指标**：国赛 vs. 美赛 5 大评审维度自适应对比卡片（无横向滚动条）+ 6 大核心精度与有效性检验指标速查（决定系数 $R^2$、MAE/RMSE、MRE/MAPE、轮廓系数 $s(i)$ 与 SSE、灰色后验差比 $C$ 与级比 $\lambda(k)$、一致性比率 $CR$ 与 $AIC/BIC$）。
- 🏆 **历年优秀论文精粹（2021–2025）**：精选 12 篇近年国赛一等奖与美赛 O 奖真题建模链路拆解，支持按赛事筛选与一键跳转站内算法交互复现。
- 🧭 **组合模型与选型指南**：5 大竞赛高频“王炸组合”建模范式 + 18 大算法选型速查表 + 获奖论文通用七步法。

### 2. 18 大核心数学建模算法（含公式通俗解读 + 直角坐标系图解 + 在线求解 + Python 代码）
每个算法均提供 **模型概述**、**建模步骤（分步 LaTeX 推导）**、**在线交互求解** 与 **Python 标准实现** 四大标签页，并配备：
- 💡 **全量公式通俗文字解读**：为每个核心公式与分步推导公式提供直白的符号含义与物理/几何解释，彻底告别晦涩难懂的纯符号堆砌。
- 📐 **高清矢量直角坐标系与几何图解**：通过自研 SVG 直角坐标系图、三维正交投影图、可行域极点跳跃图、整点切割图与相平面极限环图，将抽象代数公式转化为一目了然的几何直观。

| 算法类别 | 包含算法（共 18 项） | 核心方法与检验体系 |
| :--- | :--- | :--- |
| **评价决策类（5 项）** | **TOPSIS 法**、**层次分析法 (AHP)**、**熵权法 (EWM)**、**模糊综合评价 (FCE)**、**灰色关联分析 (GRA)** | 极大型/极小型/中间型/区间型正向化、算术/几何/特征值三法求权、一致性检验 $CR<0.10$、四种模糊合成算子、熵权-TOPSIS 组合 |
| **回归与时序预测类（5 项）** | **一元线性回归**、**多元线性回归**、**非线性回归 (Logistic/幂/指数/多项式)**、**灰色预测 GM(1,1)**、**时间序列 ARIMA(p,d,q)** | 矩阵最小二乘、LM 阻尼迭代、$t/F$ 显著性检验、VIF 多重共线性诊断、级比与后验差检验 $C/P$、Ljung-Box 白噪声检验、全套误差指标（MAE/MSE/RMSE/MRE） |
| **优化与运筹规划类（3 项）** | **线性规划与单纯形法 (LP)**、└ 子分类：**整数规划 (ILP / 0-1规划 / MILP)**、**模拟退火智能优化 (SA)** | 字典序大 $M$ 单纯形法、**分支定界法 (Branch & Bound)**、二维连续可行域与离散整点网格可视化、四舍五入陷阱诊断、松弛量分析、2-opt 旅行商路径规划 (TSP) |

| **机理动力学与随机仿真类（3 项）** | **微分方程动力学 (RK4)**、**蒙特卡洛模拟 (MC)**、**马尔可夫链 (Markov)** | 四阶龙格-库塔法 (RK4) 仿真 SEIR/SIR 传染病与 Lotka-Volterra 生态竞争相平面图、高维定积分/GBM 资产路径/$VaR_{95\%}$ 风险量化/报童库存寻优、多步状态转移与极限稳态分布 $\boldsymbol\pi^*$ |

## 🚀 本地运行与测试

无需安装任何后端依赖，直接双击打开 `index.html` 即可使用全部功能；或使用任意静态服务器预览：

```bash
npx serve .
```

如需运行内置的 21 项数值精度与完整性单元测试，可在浏览器中打开 `test-runner.html`。
