# MathModel Studio · 数学建模工作台

面向 **全国大学生数学建模竞赛（CUMCM 本科组 A/B/C 题）** 与 **美国大学生数学建模竞赛（MCM/ICM A-F 题）** 的交互式数学建模算法实验台与竞赛指南。

## 核心特性

- **竞赛与备赛专栏（5 大模块）**
  - 🇨🇳 **全国大学生数模（国赛指南）**：本科组 A / B / C 三大题型定位、历年高频考点、标配算法矩阵与官方优秀论文库直达。
  - 🌍 **美国大学生数模（美赛指南）**：MCM（A/B/C）与 ICM（D/E/F）六大题型解析、O 奖摘要（Summary Sheet）黄金法则与特等奖论文库。
  - ⚖️ **评审标准与检验指标**：国赛 vs 美赛 5 大评审维度对比卡片 + 6 大核心建模精度与统计检验指标（$R^2$、MAE/RMSE、MAPE、轮廓系数 $S(i)$、灰色后验差比值 $C$、$CR/AIC$）。
  - 🏆 **历年优秀论文库**：精选国赛与美赛典型真题解析及算法复现一键直达。
  - 🧭 **备赛路线与联用套路**：题目特征 $\to$ 数学模型选型速查与多算法联用组合范式。
- **16 大经典数学建模算法交互计算与推导**
  - **评价与决策类（5 种）**：TOPSIS 优劣解距离法、AHP 层次分析法、熵权法（EWM）、模糊综合评价（FCE）、主成分分析（PCA）。
  - **回归与预测类（5 种）**：一元线性回归、多元线性回归、灰色预测 GM(1,1)、非线性回归、ARIMA 时间序列分析。
  - **现代智能与机理类（6 种）**：蒙特卡洛模拟、马尔可夫链预测、K-Means 聚类分析、SIR 传染病微分方程、线性与整数规划（LP）、模拟退火（SA/TSP）。
